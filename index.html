생각열기 ①

대우를 이용한 증명법이란?

명제 \(p \rightarrow q\)가 참이면 그 대우 ¬q → ¬p도 참이다.

어떤 명제가 참임을 증명할 때에는 그 대우가 참임을 증명해도 된다.

빈칸을 눌러 핵심 내용을 확인해 보세요.

핵심 정리

대우를 이용하면 무엇이 달라질까?

원래 명제

p이면 q이다.

가정 p에서 결론 q를 직접 이끌어 냅니다.

대우

q가 아니면 p가 아니다.

결론이 아닌 경우를 가정하여 가정도 성립하지 않음을 보입니다.

기억하기　원래 명제와 대우는 참·거짓이 항상 같습니다.

n²이 짝수이면 n도 짝수이다

대우를 이용한 증명의 문장을 올바른 순서로 선택하세요.

  1. n이 홀수라고 가정한다.
  2. n = 2k−1 (k는 자연수)로 나타낸다.
  3. n² = (2k−1)² = 2(2k²−2k)+1이다.
  4. 따라서 n²은 홀수이다.
  5. 대우가 참이므로 원래 명제도 참이다.

정리: n²이 짝수이면 n도 짝수이다.

절대부등식의 이해와 증명

생각열기 ①

항상 성립하는 부등식은?

x²−1≤0은 −1≤x≤1일 때 성립하지만, 모든 실수에서 성립하지는 않는다.

그러나 x+5>x는 모든 실수 x에 대하여 항상 성립한다.

부등식의 문자에 어떤 실수를 대입하여도 항상 성립하는 부등식을 절대부등식이라고 한다.

함께하기 ①

다음 중 절대부등식인 것은?

절대부등식인지 판단할 때는 모든 실수에 대해 항상 성립하는지 확인합니다.

증명의 도구

두 실수 a, b에 대하여

① a>b ⇔ a−b>0

② a² ≥ 0

③ a²+b² ≥ 0

④ a²+b²=0 ⇔ a=b=0

⑤ a>0, b>0일 때 a>b ⇔ a²>b²

⑥ |a|²=a², |a||b|=|ab|, |a|≥a

함께하기 ② · 1번

a²+b²≥ab임을 증명하자

A≥B ⇔ A−B≥0을 이용합니다. 증명 순서를 조립하세요.

  1. a²+b²−ab≥0임을 보이면 된다.
  2. a²−ab+¼b²−¼b²로 나눈다.
  3. (a−½b)²+¾b²로 정리한다.
  4. (a−½b)²≥0, ¾b²≥0이므로 합은 0 이상이다.
  5. 등호는 a−½b=0, b=0, 즉 a=b=0일 때 성립한다.

제곱의 합으로 나타내면 0 이상임을 확인하기 쉽습니다.

함께하기 ② · 1번

제곱의 완성 과정을 채우자

a²+b²−ab = a²−ab+b²+b²

= (a−b)²+b²

(a−½b)²≥0, ¾b²≥0이므로 a²+b²−ab≥이다.

따라서 a²+b²≥ab이고, 등호는 a−½b=, b=, 즉 a=b=일 때 성립한다.

정답: 1/4 / 3/4 / 1/2 / 3/4 / 0 / 0 / 0 / 0

(a²+b²)(x²+y²)≥(ax+by)²

차이를 제곱식으로 바꾸는 순서를 조립하세요.

  1. (a²+b²)(x²+y²)−(ax+by)²≥0을 보인다.
  2. 전개하여 a²y²−2abxy+b²x²를 얻는다.
  3. (ay−bx)²으로 인수분해한다.
  4. (ay−bx)²≥0이므로 주어진 부등식이 성립한다.
  5. 등호는 ay−bx=0일 때 성립한다.

두 식의 차이를 하나의 제곱으로 나타냈습니다.

다음 식이 0 이상임을 보이면 된다.

(a²+b²)(x²+y²)−(ax+by)²

= a²y²−2abxy+b²x² = ()² ≥ 0

따라서 주어진 부등식이 성립하고, 등호는 =일 때 성립한다.

정사각형과 직사각형의 넓이

한 변의 길이가 a+b인 정사각형의 넓이는 색칠한 직사각형들의 넓이의 합보다 크거나 같습니다.

개념을 위한 단순화 모식도

  1. (a+b)²≥4ab이다.
  2. 등호는 a=b일 때 성립한다.
  3. a+b>0, √ab>0이다.
  4. (a+b)/2≥√ab이다.
